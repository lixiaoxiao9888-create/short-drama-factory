# 蒸馏库 · 通用机制卡

> 只存机制结构，不存任何原剧剧情/台词/人物名。持续按 SKILL.md 第十一节 SOP 扩充。
> 收录标准：能跨题材复用的冲突模板。每张卡至少 2 个变体。

## 机制卡 01：公开羞辱
- 适用赛道：女频全赛道 / 男频逆袭
- 结构：当众羞辱 → 围观者站队反派 → 主角隐忍（埋证据/身份）→ 后期当众反杀
- 变体：泼水/扇耳光；当众宣读伪造证据；直播羞辱；宴席上逐客
- 卡点配合：反杀兑现前 1 秒切断（付费卡点）

## 机制卡 02：证据反咬
- 适用赛道：豪门复仇 / 都市逆袭
- 结构：反派伪造证据陷害 → 主角暗中收集真相 → 公开场合反咬 → 伪证者当众社死
- 变体：录音反杀；合同条款反杀；鉴定报告反转；旧账翻出
- 卡点配合：证据亮出瞬间是付费峰值

## 机制卡 03：家宴审判
- 适用赛道：豪门 / 家庭伦理 / 替嫁
- 结构：全家聚餐 → 长辈当众发难 → 主角被逐/被贬 → 身份/证据揭晓 → 全员变脸
- 变体：寿宴发难；订婚宴反转；遗产宣读；认亲宴揭晓
- 卡点配合：身份揭晓前一秒

## 机制卡 04：身份揭穿（马甲掉马）
- 适用赛道：马甲/隐藏大佬 / 战神回归 / 神医赘婿
- 结构：被当废物 → 危机临头 → 被迫亮身份 → 全场震惊跪服 → 先前羞辱者清算
- 变体：隐藏身份层层剥（掉马甲多次）；身份由他人替主角揭晓；全城直播揭晓
- 卡点配合：第一次亮身份卡点，第二层身份留中后段

## 机制卡 05：当众打脸
- 适用赛道：全赛道
- 结构：反派断言主角做不到 → 主角当场做到 → 围观者立场反转 → 反派下不来台
- 变体：对赌协议打脸；考试/比试碾压；订单/合同当面抢走
- 卡点配合：兑现动作完成前 1 秒

## 机制卡 06：反转认亲
- 适用赛道：萌宝/团宠 / 豪门认亲
- 结构：主角被逐出家门 → 被弃多年 → 豪门长辈带证据寻回 → 弃子反成继承人
- 变体：DNA报告认亲；萌宝带出信物；绝症前真相揭露
- 卡点配合：认亲证据揭晓前一秒

## 机制卡 07：下跪挽回（追妻火葬场）
- 适用赛道：替嫁/追妻火葬场 / 虐恋
- 结构：男主前期冷漠伤害 → 真相揭开后悔 → 当众/雨夜下跪挽回 → 女主态度抉择
- 变体：当众下跪；雨夜守候；放弃全部身家换原谅；迟来的救命之恩揭晓
- 卡点配合：女主最终回应前一秒（可留开放式悬念）

## 机制卡 08：逐出家门
- 适用赛道：豪门 / 重生复仇
- 结构：主角被家族驱逐 → 流落底层 → 暗中崛起 → 家族求回被拒/高攀不起
- 变体：扫地出门时被收留；带着秘密离开；多年后以更高身份回归
- 卡点配合：回归身份揭晓

## 机制卡 09：遗嘱风波
- 适用赛道：豪门 / 家庭伦理
- 结构：长辈骤逝 → 遗嘱未公布 → 全员争产 → 遗嘱内容多次反转 → 真正继承人意外揭晓
- 变体：真假遗嘱；临终录音；股权代持揭晓
- 卡点配合：遗嘱真实内容揭晓

## 机制卡 10：直播曝光
- 适用赛道：都市逆袭 / 复仇
- 结构：主角被全网污名 → 直播自证/他人实锤 → 舆论反转 → 反派被反噬
- 变体：直播对线；视频实锤流出；千万粉丝号扒皮
- 卡点配合：实锤放出前一秒
