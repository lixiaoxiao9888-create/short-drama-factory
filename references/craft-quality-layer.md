# 戏剧工艺层（通用质量底座 · 红果适配版 · v5.0 升级）

> **定位**：本文件补的是**机检照不到的那一层**——"结构合规但戏是假的、没画面支撑、节奏原地打转、台词绕弯子听不懂、设定降智违背常识"。机检（`validate_episode.py`）负责硬指标兜底；本层专治戏剧因果、礼法/现实逻辑排雷、画面支撑密度、15秒换挡推进与零门槛直给表达。
>
> **触发**：立项排雷、写新集正文前、处理"平铺直叙/没画面支撑/节奏不对/说的话想半天才能明白/设定降智出戏"、以及长档双回合写得像两段平行事件时，**必读**。

---

## §〇 分层原则（最重要，先读这条）

本 skill 有两层规则，**冲突时永远是硬约束赢**：

| 层级 | 内容 | 性质 |
|---|---|---|
| **外层·红果平台适配** | 档位体量、场景上限、黄金前 3 秒、每集断章、付费墙区间、单句上限、合规红线、干聊断层上限 | **硬约束**，机检强制，不得以"质量优先"绕过 |
| **内层·戏剧工艺** | 本文件全部内容：礼法/常识逻辑是否成立、因果是否闭环、画面是否有支撑、节奏是否换挡、台词是否一秒听懂 | **质量层**，用于诊断与生成 |

## §一 先辨真瓶颈：五问定因

用户或观众反馈"没画面、节奏不对、说的话想半天才能明白、没张力"时，**不要盲目加字、加形容词、加吵架**。先按顺序过这五问，定位到哪一环断了：

1. **人物此刻是否有一个清楚的即时目标？**（不是"想复仇"，而是"这一场他要让对方做什么/交出什么/保住什么"）
2. **阻碍是否主动作用在这个目标上？**（对方有自己想要的筹码，不是站着等他表演）
3. **人物是否被迫做出选择并付诸可见行动？**（而不是站在原地纯靠嘴皮子干聊）
4. **结果是否在每 15~30 秒内改变了局面？**（信息 / 关系 / 资源 / 位置 / 危险 / 身体 / 资格 / 认知）
5. **下一场是否由这个结果直接触发？**（严禁第 1 场在客厅吵某事，第 2 场又回客厅吵同一件事）

- 五问任一缺失 → **优先修因果、换挡与场面功能**。
- 五问全部成立、但读起来仍干瘪或费解 → 立即检查 **§四·补（强画面三大视觉锚点）** 与 **§六·补（大白话同轮直给 & 礼法常识排雷）**。

## §二 戏剧生成链（写场前在内部跑一遍，不进正文）

承重场写前，用这条线找戏：

```text
上一结果造成的压力
  ➔ 人物当前判断／误判（可以有自欺、侥幸、嘴硬）
  ➔ 他认为可行的办法（必须能演出来，不是一种心情）
  ➔ 对方或规则的反作用
  ➔ 可见代价或意外收益
  ➔ 人物认出、否认或误读结果
  ➔ 下一次选择
```

**这是一条因果诊断线，不是七段式正文模板。** 平静相处、照料、等待、纯喜剧、情绪余波不必补齐每一项；但**承重场若只有"人物做了一件事"——没有依据、没有反作用、没有改变、没有后续，就还没写完这场戏。**

## §三 单场成立七问

每个承重场跑一遍：

1. 谁在争取什么？
2. 为什么**必须此刻**争取？（拖延的代价是什么）
3. 谁或什么在阻碍他？
4. 他采取了什么**具体策略**？
5. 阻碍如何**反作用**？
6. 结果与他的预期**偏差**在哪？
7. **场末相较场初改变了什么？**（信息/关系/资源/位置/危险/资格/身体/承诺/下一选择）

第 7 问是命门。若人物从怀疑开始、争论完仍以**同样的怀疑和同样的办法**离开——这场就是空场，优先改行动关系，**不要靠把声音写大来充当推进**。

---

### §三·补 集内结算（单集情绪出口）

竖屏单集必须给观众一个**可见的"出一口气"**：主角反将一次 + 反派为本次施压**付出可见代价**（当众失面／盘算落空／被架住进退两难）。

- 只堆受辱（哪怕冲突再密、证据再多）而不给结算 → 观众的情绪出口被堵死，结尾断崖；
- 判据一句话：把这一集从头看到底，**反派有没有为她的施压付账**？没有，就是"直线受辱"；
- **信号闭环（硬）**：伏笔/异能/玄学信号也要有结算——必须给「**信号 → 当场可验证 → 产生作用**」三步。

## §四 三线可见变化与「强画面支撑」三大锚点（v4.9/v5.0 重点强化）

竖屏信息量低，观众靠**可见物**跟状态。全程维护三条线，让它们在本集内有可指出的变化：

| 线 | 追踪什么 | 本集至少要回答 |
|---|---|---|
| **身体线** | 伤势、呼吸、站姿、能否起身、距离与接触 | 谁的身体状态变了？变了之后他能做什么、不能做什么？ |
| **空间线** | 相对出口、危险源、关键地标、彼此的站位 | 权力关系变化有没有落到位置上（谁退、谁逼近、谁被挡在门外）？ |
| **道具线** | 关键物件从哪来、在谁手里、状态怎么变、最后去哪 | 本集的"铁证/信物/条子/存折"结束后在谁手上？ |

### §四·补 彻底解决「没有画面支撑」：每 2~4 句必插强视觉 `△`（机检 E24/E26/E27）

1. **穿插密度硬纪律**：**每 2~4 句对白之间，必须穿插 1 条实质性 `△` 动作行！** 连续纯对白一旦达到 **7 行** 没有任何 `△` 动作支撑，机检 `E24` 直接告警！
2. **三大强视觉锚点（每条 `△` 必须至少命中其一，做到静音看 `△` 就能看懂戏）**：
   - **锚点 A · 物理结果与视觉奇观**：动作必须带出可见的物理改变或生理反应（如：`△ 雪茄狠狠摁在洗得发白的衣领上，青烟直冒`、`△ 滚烫药汁泼在青砖地上，瞬间冒起白沫`）。
   - **锚点 B · 身份反差与手头忙活**：拒绝站桩说话！让角色边做极具反差感的具体动作边说话（如：`△ 满身绫罗的侯门主母蹲在泥地里慢条斯理拨算盘，算珠噼啪作响`）。
   - **锚点 C · 物证亮牌与肢体对抗**：台词提到什么物证，画面必须立刻拍出对该物证的具体操作（如：`△ 她一把抓起粗瓷碗翻过来，手指在干巴巴的碗底抹出一层白面粉`）。
3. **无效微动作黑名单（机检 E26 拦截）**：严禁单独使用 `眼神微动 / 目光微闪 / 微微一怔 / 若有所思 / 嘴角微扬 / 叹了口气 / 把杯子推了半寸` 充当独立动作行！
4. **反机械分镜标签刷屏（v5.0 新增 · 机检 E27 拦截）**：文字剧本不是摄影机说明书！**严禁每集末尾机械刷屏 `△ 【特写】` + `△ 【慢镜头】` 标签来凑高潮**（单集 `【慢镜头】` >=2 处或 `【特写】` >=6 处即触发 `E27` 告警）。真正的高潮靠具体的物理结果与动作张力体现，而非贴标签。

## §五 因果接力与防原地踏步

每个转场尝试写成一句话：

> 因为上一场发生了 X，人物现在必须去 Y 做 Z，否则会失去 W。

- **严禁同集同场景原地踏步**：绝不允许第 1 场在某房间争论一件事，第 2/3 场还在同一个房间（或换个房间）用同样的话术争论同一件事；
- **严禁全剧机械锁死场次数与句数**：标准档建议 <=2 场、长档 <=3 场，但**严禁像机器八股一样把 40 集全部写成死板的“固定 N-1/N-2 两场、每集卡死30句、全是公堂/大堂嘴仗”**——剧情需要时可单场打穿到底，也可穿插私密潜入、动作对决与情感低谷场。

## §六 概念负荷最小登记与「大白话同轮直给」（v4.9 重点强化）

### §六·补 彻底解决「说的话想半天才能明白什么意思」（机检 E25）

1. **物证 + 大白话结论同轮直给**：凡指出物证或反常细节，**必须在同一轮对话里用大白话把结论直接砸出来**。
2. **设定词/行话当句人话翻译**：凡出现行业术语、商战概念、医学名词、古语或玄学设定词，**当句或下一句必须立刻翻译成大白话世俗利害（多少钱、判几年、谁死谁活）**（机检 `E25` 拦截）。

### §六·补二 立项「常识与礼法/现实逻辑排雷清单 + 六栏世界规则卡」（v5.0 新增 · 吸收粉丝参考剧本精华）

为什么有的爽剧爽得高级、有的爽剧开场 3 分钟就被观众骂“编剧没常识”划走？因为没做**立项逻辑排雷**！在 `/立项大纲` 与开写第 1 集前，必须过一遍下表，把降智老梗替换为**既合规合理、又让利益痛感翻倍**的高级博弈：

| 常见降智雷区（严禁照搬） | 为什么会让观众出戏（逻辑硬伤） | ✅ v5.0 高级利益置换写法（痛感更强、逻辑铁板一块） |
|---|---|---|
| **古装：当众“贬妻为妾”** | 历朝律法皆禁“以妻为妾”（唐明清律均杖责并离异），正妻是两姓联姻，夫家无权单方降妾 | 改为**「逼签七出之首“无子”休书 vs 正式和离」**：按律无子被休嫁妆充公留夫家；正式和离则陪嫁分文不留全退——把名分之争直接变成**几十万两真金白银的生死算盘**！ |
| **古装：主角带人“私拆御赐牌匾”** | 御赐牌匾象征皇权，私拆等同大不敬/谋逆，反派一告一个准 | 改为**「只搬走自己嫁妆/欠债抵扣的私产家具，让反派顶着高悬的御赐牌匾坐在空堂水泥地上吃瘪」**——画面讽刺感拉满且主角零把柄！ |
| **古装/现代：主角当众“撕毁自己手里的借据/合同原件”耍帅** | 撕毁债权原契等于自毁法律证据，纯属脑残耍帅 | 改为**「只撕毁对方手里的“展期副契/作废草约”，而把盖有红印的原始主契当众拍在桌上入库封存」**！ |
| **古装：外室/小配角随手传唤“太医院院判/大理寺卿”当跟班** | 朝廷正三品/四品命官绝不可能给无品级外室当私人保镖 | 改为**「外室花重金买通被革职的医官冒充太医造假，结果被主角请来的真太医院院判/官府命官当场拆穿拿下」**！ |
| **现代：霸总一句话“十分钟内冻结跨国银行所有账户/让百亿国企破产”** | 银行冻结需司法裁定，口头冻结悬浮假大空 | 改为**「当场撤回实控人过桥资金 / 触发对赌协议穿仓条款 / 吊销独家核心专利授权 / 亮出法院诉前财产保全裁定书」**！ |

#### 立项必填：六栏世界规则卡（防前后吃书 & 防玛丽苏无危机）
立项时用 6 行锁定本剧底层规则：
1. **【权力上限】**：本剧最高裁决机构是谁？（如：大理寺三司会审 / 集团董事会+证监会，绝不写穿天际）
2. **【利益链条】**：双方争夺的具体货币是什么？（如：十八万两现银嫁妆 + 三十六万两红契欠据 + 江南三成盐引）
3. **【空间壁垒】**：从 L1 到 L4 四个单元分别在什么物理空间升级？（如：内宅正堂 ➔ 京城商行/顺天府 ➔ 尚书府夜宴 ➔ 奉天殿三司会审）
4. **【核心物证】**：贯穿全剧的 3~4 件硬物证是什么？（如：和离书、四海商行少东家金印、太医院滑脉黑账、伪造公章）
5. **【金手指边界与代价锁】（★必填）**：主角的能力/底牌有什么**物理或规则限制**？（如：心算巅峰极耗心神，连续高压算账会引发右手麻木三天无法拨算盘——**到了中段第 17~20 集强制触发该代价，既破除全知全能的机械疲劳，又能顺势让男主/盟友替她拨算盘，自然打出“他做她的手”的 CP 高光！**）
6. **【称谓阶梯】**：角色关系变化如何体现在称呼上？（如：沈氏 ➔ 沈大小姐 ➔ 沈少东家；王爷 ➔ 萧景珩）

## §七 远简近详的写作状态包（连写 60～100 集防走形）

批量连写时，**每一集只携带当前范围需要的信息**，不要把全套人物小传、评审清单、未来谜底同时塞进每一集：

- 全剧故事发动机 + 六栏世界规则卡（不可变事实）；
- 较远阶段的简要方向（不展开）；
- **最近一到两集的实际结果**、关键原文、尚未消失的身体／道具／关系状态；
- 当前集双方的目标、认知、隐瞒、预期转折；
- 本集主导变化、阶段兑现、下一压力。

---

## §八 七级修订顺序

发现多个问题时，按影响排，不按"好改的先改"：

1. 前后接口与硬事实（礼法常识排雷、时代、人名、时间线、道具归属）；
2. 人物动机、信息权限、空间连续；
3. 单场功能与单集 15 秒换挡／第 1 集半场反制／单元闭环；
4. 敌我策略与代价；
5. 强画面 `△` 支撑密度（消除连续干聊、无效微动作与机械镜头标签）；
6. 对白大白话直给度、快慢变速、去括号常态套话、角色语言指纹；
7. 格式、错字、标记、屏幕文字清单。

---

## §九 竖屏落点（把工艺层翻成可拍的画面）

- 动作写"能演出来的"：保留决定理解的对象、阻力、结果和反应；
- 每 2~4 句对白穿插一条强画面 `△`，用动作切割长对话；
- 微表情只写**生理可观测动作**（喉结滚动、指甲掐进掌心、耳根发红），不写"他内心五味杂陈"。

---

## §十 禁止事项（工艺层专属）

1. 用作者结论（"气氛压抑""他明白了"）代替可见反应；
2. 连续 7 句以上纯对白不给任何 `△` 动作支撑（站桩广播剧，E24）；
3. 只给物证不给大白话结论，或用问 A 答 B 的文艺腔打哑谜；
4. 抛出未翻译的行业黑话、自造玄学词让观众猜半天（E25）；
5. 同集内同场景原地踏步、反复咀嚼同一句台词；
6. 用 `眼神微动 / 微微一怔 / 推了半寸` 等镜头拍不出来的无效微动作充数（E26）；
7. 每集机械复制 `△ 【特写】` + `△ 【慢镜头】` 标签充当高潮（E27），或全剧死板锁死每集 30 句/双场景；
8. 触犯立项礼法与常识排雷表中的降智桥段（贬妻为妾/私拆御匾/撕自己手里的原契）。


### §四·补二 视听可拍性四门禁（v5.1 新增 · 机检 E37~E40）

纯剧本虽不写分镜，但必须保证**每一条 `△` 和每一句对白都能被摄影机拍出来、被演员演出来**：

1. **禁否定式伪动作（`E37` FAIL）**：严禁在 `△` 中写 `非但没跪 / 非但没退 / 看都没看一眼 / 连眼角都没扫 / 连眼皮都没抬一下` 等“拍不出来的否定句”，必须改写为正向可见动作（如：`△ 林辰负手立在堂中，下巴微抬，目光越过众人落在主位`）。
2. **道具交接来源闭环（`E38` WARN）**：`△` 中凡出现“接过 XX”，必须写明从哪位在场角色手中接过（如：`△ 沈知微从侍卫阿七手里接过匣子`），严禁无来源凭空接物。
3. **禁台词未提先知 / 幽灵反问（`E39` WARN）**：前文从未提及、且角色未通过物证/在场旁听获得的专名，后句严禁突然反问 `什么XX？`，必须先亮物证或先由对手抛话头。
4. **禁同空间假切场（`E40` WARN）**：相邻两场 `[场景]` 完全相同且无真实位移或时间跳转词，严禁硬拆两场；真需要转场，新场首条 `△` 必须写清人物位移（推门/走进/离开）或时间过渡（片刻后/次日/当晚）。

### §六·补三 优化 ≠ 改编路径消歧与第一性原理降维外化（v5.1 新增）

1. **路径消歧铁律（保留外壳 vs 换壳重生）**：
   - 当用户带着**自己已写好的草稿**要求 `/剧本医生` 或 `/剧本优化` 时，**严禁改剧名、严禁改主角姓名、严禁推翻原有世界观**；立项规则卡由 `python scripts/extract_world_rules.py` 从原稿正文自动反填，绝不反问用户卡死流程。
   - 只有用户明确要求对标外部作品做**仿写/改编**时，才执行《剥壳留核》清零原外壳。
2. **第一性原理叙事降维外化**：
   - 遇到容易算错、逻辑漏洞大的一次性超自然补丁（如纯靠倒计时/读心术/系统硬推），优先将其**降维外化**为「人物关系见证 + 主动互相试探与反试探」，用真实的利益博弈和信息差代替机械金手指，既防逻辑穿帮又把情绪张力翻倍。
