# 单集场景写作规范（v1.1·来源：AI影视-剧本与叙事 + 山音-叙事短片）

> 配套：SKILL.md 2.7 节。单集正文写作的底层执行标准。

## 场景基础

- **场为基础单位**：地点 + 时间 + 内外景，任一变化 = 新场次
- 场景标题格式：`场景名 · 内/外 · 时间 · 地点`

## Beat 拆分法

- beat = 最小叙事单元
- **情绪不变 + 动作不变 = 一个 beat**；任一变化 = 新 beat
- 单场戏判定：开场情绪 vs 结尾情绪有变化 = 有叙事价值
- 量化公式：`文字篇幅 = 镜头时长 = 剧情重要程度`

## 写作句式

- 一句话一个镜头，禁止长句堆叠
- 动作主谓宾主动句式："她推开窗" ✓；"窗被推开" ✗
- 核心动作写死，非关键细节留白给导演发挥（粗中有细）

## 每场=微型戏剧动作

每个情节点拆解为：目标 → 障碍 → 结果
每场戏标注双轨节奏：情节（松/中/紧）× 情感（轻/中/重）

自检：
- 时长累计吻合？
- 无连续 3 场以上同一节奏？
- 至少一处情节/情感错位？

## 单集结构（四段式 + 时长预算）

- 冷开场：片头前内容，唯一任务让观众"继续看"，单独拿出来必须精彩
- 建置 15% → 发展 40%（障碍1→障碍2，障碍2不同质）→ 高潮 25% → 结局+集末钩子 20%
- 前史通过对白和视觉线索自然散落，不用集中闪回

## 竖屏短剧正文格式示例

```
【第N集 集名】

场景1：苏家客厅 · 内 · 夜
（beat 1：动作）苏晚走下楼梯，步子很稳。
（beat 2：对白）苏柔：苏晚！你偷我妈的玉镯！
（beat 3：动作反制）苏晚弯腰，从茶几下抽出另一只玉镯。
苏晚：镯子，是苏柔昨晚自己放的。
（集尾金句）苏晚：三年前你诬陷我一次。这辈子，不会了。
```

## 常见错误

- 心理描写（"她意识到…"）→ 改用动作+反应
- 长句堆叠 → 一句话一个镜头
- 障碍2省略或与障碍1同质 → 必须两次不同质的递进
- 前史集中闪回 → 散落在对白和视觉线索里
- 集末钩子强行制造 → 钩子是故事自然延伸
