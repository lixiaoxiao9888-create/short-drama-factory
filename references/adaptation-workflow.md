# 网文改编工作流（v1.1·来源：小逻-影视剧本原创改编）

> 网文/长文档 → 短剧。必须完成深层结构重构，禁止表面改编。
> 配套：SKILL.md 7.4 节 + 9.1 节原创性边界。

## Step 1 原故事价值提炼

只提炼抽象价值，不复述大段剧情。

- 核心主题
- 主线冲突
- 主角欲望
- 情绪曲线
- 类型承诺
- 商业卖点
- 最有效的戏剧机制
- 当前文本的结构弱点

输出表：

| 项目 | 原素材中的功能 | 是否保留 | 保留层级 | 重构方向 |
|------|--------------|---------|---------|---------|
| ... | | | | |

保留层级只能写：抽象主题 / 冲突类型 / 情绪功能 / 类型机制 / 不保留

## Step 2 相似性风险拆解

扫描：高辨识度人物组合、特殊世界规则、独特组织与权力体系、标志事件与事件顺序、特有反转、独特道具或视觉符号、可识别对白、专有名词、高辨识度结局。

输出表：

| 风险元素 | 风险类型 | 为什么可识别 | 重构原则 | 新方案方向 |
|---------|---------|-------------|---------|-----------|
| ... | | | | |

风险等级：
- 高：保留后仍可直接识别来源作品 → 必须重构
- 中：单独常见，但与其他元素组合后高度相似 → 组合层面重构
- 低：题材惯例或抽象戏剧机制 → 可保留

## Step 3 深层重构

### 可保留的抽象层（仅用户需要时保留）

- 核心主题命题
- 冲突的抽象类型
- 大尺度情绪曲线
- 类型片承诺
- 一般性叙事功能
- 商业观看机制

### 必须重新创造的具体层

- 人物姓名、身份、职业、关系与人生经历
- 世界时代、地理环境、社会规则与权力结构
- 主角目标、反派策略、利益链和冲突原因
- 事件起因、行动方案、转折触发与解决方式
- 场景、建筑、关键道具、符号和视觉母题
- 场次顺序、信息释放方式和高潮选择
- 对白、语言习惯、潜台词与喜剧或悬疑机制
- 结局行动、主题回应和人物最终代价

### 禁止的表面改编

- 只替换名字、职业或地名
- 保留原人物关系图，仅改变身份外壳
- 按原场次一一对应地换皮
- 保留同样的标志事件、反转原因和解决方式
- 复制或同义改写原对白
- 保留原作品专有世界规则、独特组织或标志物
- 用"相似比例"或简单改动数量宣称原创

## 来源与权利处理

1. 先识别素材来源：用户原创 / 已获授权 / 公共领域 / 事实材料 / 第三方作品
2. 用户未说明来源时，按"来源未确认"处理，采用更高强度的原创重构
3. 对用户原创或已授权素材，可按用户要求保留更多结构资产
4. 对第三方作品，只提炼主题、类型和通用戏剧机制，不延续可识别人物、世界、专有设定、独特事件链或对白
5. 不承诺"绝对无版权风险"或"保证通过审核"，输出定位为创意相似性筛查，不替代法律意见
6. 若用户要求复刻特定创作者风格，改为提炼高层特征（节奏、叙事密度、镜头距离、类型气质）
7. 对真实品牌、公众人物和敏感现实机构，除非明确授权或确有必要，否则使用原创虚构替代
