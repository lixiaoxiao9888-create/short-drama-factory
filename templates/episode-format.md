# 单集剧本标准排版（Episode Format）

> 交付格式模板。写完必须过 `python3 scripts/validate_episode.py <文件>`（`--format standard|long|manju`，默认自动分档）。

**先定档位再动笔**（篇幅制式，三选一；规格见 `references/hongguo-beat-sheet.md` §三）：

| 档位 | 时长 | 正文体量（实拍 / 漫剧） | 场景 | 单集拍数 | 机检 |
|---|---|---|---|---|---|
| 标准档（默认） | 90～120 秒 | 350～500 / 260～400 | ≤2 | 1 拍 | `--format standard` |
| 长档 | 165～195 秒 | 650～850 / 520～680 | ≤3 | 2 拍 + 中段小钩 | `--format long` |
| 漫剧档 | 60～90 秒 | 260～400 | ≤2 | 1 拍 | `--format manju` |

## 一、 标准档 / 漫剧档模板

```text
第【XX】集：【集名/核心爽点标签】
【所属阶段】：第X幕・（第 X/80 集 ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：五母型之一（生死绝境/极端羞辱/身份暴涨/物证背叛/规则悬念）
【情绪流变】：A ➔ B ➔ C ➔ 绝命断章
【本集时长】：__ 秒（约 __ 字）

[场景]：内景/外景・地点・日/夜        ← 全集 ≤2 个
[人物]：名（状态标签）、名（标签）      ← 名字须在人物账

△ 特写/中景：只写生理可观测动作与物理事件，禁抽象心理词。
角色名（神态短语）：
"台词。"                              ← 常规 12~18 字 / 爆发金句 8~12，硬上限 ≤25 字；对白行 ≥4

【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```

## 二、 长档模板（约 3 分钟）

```text
第【XX】集：【集名/核心爽点标签】（长档·约3分钟）
【所属阶段】：第X幕・（第 X/40 集 ｜ 单元A ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：五母型之一
【情绪流变】：A ➔ B ➔ C ➔ D ➔ 绝命断章
【本集时长】：__ 秒（约 __ 字）
【本集结构】：双回合（回合A ____ ➔ 回合B ____）    ← 本集时间骨架：钩 0~8s / 回合A 8~80s / 小钩≈90s / 回合B 95~170s / 断章 170~195s

[场景]：内景/外景・地点・日/夜        ← 全集 ≤3 个，第 2/3 场必须是升级场（换空间/换对手/换压力等级）
[人物]：名（状态标签）、名（标签）

△ 特写/中景：钩子——直接切入冲突顶点，禁铺垫。
角色名（神态短语）：
"台词。"                              ← 回合A：施压 ➔ 反驳，反驳必须带代价或新信息；对白行 ≥8

【本集中段小钩】：≈90 秒处的新信息/新威胁/反转半步，只抬价不爆点。（机检必查）

△ 中景：回合B —— 升级施压（新证据/新代价/新人证）。
角色名（神态短语）：
"台词。"                              ← 升级反驳/翻盘未遂，禁复读回合A 话术
△ 中景：情绪顶点落地 + 静默反应镜头

【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```

**写前**：读台账 + 回合表定位本集档位与拍数；**写后**：更新台账四账 + 按档跑机检。
