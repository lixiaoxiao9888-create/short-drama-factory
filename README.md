## 篇幅三档

| 档位 | 单集时长 | 正文体量 | 单集拍数 | 全剧集数档 |
|---|---|---|---|---|
| **标准档（默认）** | 90～120 秒 | 480～850 字 | 1 拍（内含 15s 四挡推进） | 60 / 80 / 100 |
| **长档** | 150～195 秒 | 820～1400 字 | 双回合 + 中段小钩 | 30 / 40 / 50 |
| **漫剧档** | 60～90 秒 | 330～620 字 | 1 拍 | 60 / 80 / 100 |

长档不是注水拉长：一集必须装两个往返回合（施压与反驳各升一档）+ ≈90 秒处中段小钩；全剧按内容量守恒折算（1 长档集 ≈ 2 标准集），四幕、单元链、付费墙同步换算。

## 核心方法论

**情绪契约单元链 × L1~L4 四级圈层阶梯**——全剧锚定的是观众每集要续期的“那口气”，矛盾只是单元载具：

- 🎯 **单矛盾硬帽 20～30 集必闭环**（长档折半 10～15 集；60 集 = 2～3 单元 / 80 集 = 3 / 100 集 = 3～4）
- 🪜 **L1~L4 四级被看见圈层升维**（v5.0）：`L1 内宅/基层 ➔ L2 行业/城际 ➔ L3 权贵/名流 ➔ L4 中枢/天下`，每单元同步更换更高阶围观裁判与【质疑者配角】（嘴替），彻底防中后段注水
- 🔄 **三缝合一换矛盾**：旧单元残渣生新矛盾（火种埋钩）/ 对手换层不换欲 / 弧光随单元升级——换矛不断气
- 💰 **付费墙挂单元接缝**：换矛盾点即天然强付费点；中点攻守转换对位第一付费墙

**v5.1 跨集防崩、视听可拍性与优化消歧升级**：

- 🛡️ **视听可拍性四门禁（`E37~E40`）**：不越界写分镜，但拦截“非但没跪/看都没看一眼”等否定式伪动作（`E37`）、无来源接过道具（`E38`）、台词未提先知幽灵反问（`E39`）与同空间假切场（`E40`）
- 🔁 **长剧防崩与三态交付终检**：每 5~10 集用 `rolling_checkpoint.py` 生成抗上下文压缩滚动状态包；交付前跑 `final_qc.py`（联动 `validate_series.py` + 跨集断章接续 `C1`），严格输出 `PASS(0)` / `BLOCKED(1)` / `INCOMPLETE(3)`，配套一页式 L1~L5 逻辑交接表
- ✍️ **「优化 ≠ 改编」路径消歧 + 规则卡反填**：`/剧本优化` 锁死保留原稿剧名、主角名与外壳，`extract_world_rules.py` 从原稿自动反填六栏世界规则卡，不卡流程；仿写层补齐「第一性原理叙事降维外化」
- 🔌 **结构化 JSON 导出 + 一键全检**：`export_script_json.py` 将标准剧本一键解析为 JSON 对接下游分镜/平台；`run_all_checks.py` 一条命令跑完全套 6 个引擎自检与双标杆样章验证

**单集实战铁律（v4.9/v5.0 底座）**：

- ⚡ **前三集极速进场五步法 + 女频 A/B 双轨制**：`0~3s` 视觉砸脸 ➔ 前 5 句挑明算盘 ➔ 第 1 集半场必亮首张反制牌；A轨当场掀桌（E3 留深层火种防早泄）vs B轨蓄力刀人回放
- 👀 **强画面支撑三大锚点**：每 2~4 句对白必插 1 条强视觉 `△`（`E24` 拦干聊、`E26` 拦无效微动作、`E27` 拦机械刷屏【慢镜头】）
- 🗣️ **大白话同轮直给 + 去常态套话**：物证与结论同轮挑明、设定黑话当句翻译（`E25`）、括号禁写“眼神微冷/淡淡开口”（`E18c`）

## 快速开始

```bash
# 安装到技能目录后直接对话："写短剧" "立项：赘婿战神" "/长档大纲 40集" "/连写 1-5" "/终检"
# 命令按 Windows 写 python；macOS / Linux 用 python3

# 1. 一键跑完全套 6 个脚本引擎自检 + 双标杆样章校验
python scripts/run_all_checks.py

# 2. 单集机检（E1~E27 + E37~E40 视听可拍性 + N12~N14）
python scripts/validate_episode.py examples/ep01-longwang-demo.md --format standard
python scripts/validate_episode.py examples/long-format-3min-demo.md --format long

# 3. 剧本优化起手式：从已有草稿自动反填世界规则卡（不反问用户）
python scripts/extract_world_rules.py <已有剧本.md或目录> -o world-rules.json

# 4. 批量连写每 5~10 集生成滚动状态包 & 交付前终检（PASS=0 / BLOCKED=1 / INCOMPLETE=3）
python scripts/rolling_checkpoint.py <剧本目录> --out rolling-state.md
python scripts/final_qc.py <剧本目录> --ledger <台账.md> --out 终检报告.md

# 5. 结构化 JSON 导出（对接下游分镜/平台）
python scripts/export_script_json.py examples/ep01-longwang-demo.md -o ep01.json
```
