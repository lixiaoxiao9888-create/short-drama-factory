## 篇幅三档

| 档位 | 单集时长 | 正文体量 | 单集拍数 | 全剧集数档 |
|---|---|---|---|---|
| 标准档（默认） | 90～120 秒 | 480～850 字 | 1 拍（内含 15s 四挡推进） | 60 / 80 / 100 |
| **长档** | **150～195 秒** | **820～1400 字** | **双回合 + 中段小钩** | **30 / 40 / 50** |
| 漫剧档 | 60～90 秒 | 330～620 字 | 1 拍 | 60 / 80 / 100 |

> 长档不是注水拉长：一集必须装**两个往返回合**（施压与反驳各升一档）+ ≈90 秒处**中段小钩**；全剧按内容量守恒折算（1 长档集 ≈ 2 标准集），四幕、单元链、付费墙同步换算。

## 核心方法论

1. **情绪契约单元链**——全剧锚定的是观众每集要续期的"那口气"，矛盾只是单元载具：
   - 🎯 **单矛盾硬帽 20～30 集必闭环**（长档折半 10～15 集；60 集 = 2～3 单元 / 80 集 = 3 / 100 集 = 3～4）
   - 🔄 **三缝合一换矛盾**：旧单元残渣生新矛盾（火种埋钩）/ 对手换层不换欲 / 弧光随单元升级——换矛不断气
   - 📊 **每单元一张往返回合表**：六档证据阶梯 × 六档反驳成本阶梯，单元间靠情绪契约接力
   - 💰 **付费墙挂单元接缝**：换矛盾点即天然强付费点；中点攻守转换对位第一付费墙
2. **单集实战三大铁律（v4.9 新增 · 专治干聊广播剧与谜语人台词）**：
   - 👀 **强画面支撑三大锚点**：每 2~4 句对白必插 1 条强视觉 `△`（物理结果奇观 / 身份反差忙活 / 物证亮牌对抗），连续纯对白严禁超过 6 行（`E24`），封杀“眼神微动/推半寸”无效微动作（`E26`）
   - ⚡ **单集 15 秒换挡四拍表**：`0~15s` 抓人立事 ➔ `15~45s` 正面交锋 ➔ `45~85s` 亮牌翻转（完成本集结算） ➔ `85~110s` 余波钩子，严禁同集原地打转
   - 🗣️ **大白话同轮直给 + 快慢变速**：物证指认与大白话结论必须在同一轮直给，专业术语/设定黑话当句换算成钱/命/地位（`E25`），`3~6字` 短促快刀句与 `8~16字` 算账句交替咬合
